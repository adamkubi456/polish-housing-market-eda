# EDAproject
Eksploracyjna analiza danych (EDA) polskiego rynku nieruchomości, oparta na danych ofertowych mieszkań z platformy Kaggle

Projekt bada kluczowe czynniki kształtujące ceny lokali w największych miastach Polski. Repozytorium obejmuje proces czyszczenia surowego zbioru, identyfikację wartości odstających oraz wizualizację najciekawszych trendów cenowych.

//eng

This project investigates key drivers behind property prices across major Polish cities. The repository covers raw data preprocessing, outlier detection, and visualization of core pricing trends.
